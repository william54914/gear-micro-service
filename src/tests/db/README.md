# Database Tests and Utilities

This directory contains database-related tests, migrations, and utility scripts:

## Structure
- `migrations/` - Database migration scripts and utilities
- `sql/` - SQL scripts for database operations
- `utils/` - Database utility scripts (cleanup, checks, etc.)

## Categories
1. Table Management
   - Creation/dropping tables
   - Adding indexes
   - Schema modifications

2. Data Operations
   - Truncating/clearing data
   - Seeding test data
   - Data validation scripts

3. Maintenance
   - Database cleanup
   - Status checks
   - Schema verification
